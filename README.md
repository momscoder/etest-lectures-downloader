# etest lectures downloader
Расширение для браузера, добавляющее кнопку **«Скачать PDF»** к слайдеру лекций на [etest.bsmu.by](https://etest.bsmu.by). Позволяет сохранять слайды и материалы лекций в один клик — без ручного скачивания каждого изображения.
> ⚠️ Расширение предназначено для личного использования — для офлайн-подготовки к занятиям и повторения материала. Пожалуйста, уважайте авторские права преподавателей и не распространяйте скачанные материалы без разрешения.

## Установка
1. Скачайте [последний архив](../../releases/latest)
2. Распакуйте его в удобную папку.
3. Откройте страницу управления расширениями:
   - Chrome:  `chrome://extensions/`
   - Edge:    `edge://extensions/`
   - Yandex:  `browser://extensions/`
4. Включите **«Режим разработчика»** (Developer mode).
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку с расширением.

## Использование
1. Откройте любую лекцию на [etest.bsmu.by](https://etest.bsmu.by) со слайдером.
2. В панели слайдера появится кнопка **«Скачать PDF»**.
3. Нажмите её — расширение соберёт все слайды и сохранит архив.
4. Готовый ZIP-файл окажется в папке загрузок браузера.

## Безопасность и приватность
- Расширение **не собирает** и **не передаёт** никакие данные на сторонние серверы.
- Все файлы обрабатываются локально в браузере.
- Запрашиваемые разрешения: `downloads`, `activeTab`, доступ к домену `etest.bsmu.by`.
